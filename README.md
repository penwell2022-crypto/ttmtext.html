# ฝึกธาตุ 4 · ทบทวนและแบบฝึกหัด

เว็บทบทวนและแบบฝึกหัดเรื่องธาตุ 4 จากแพทยศาสตร์สงเคราะห์ เล่ม 1–2
ครบ 15 คัมภีร์: ฉันทศาสตร์ ปฐมจินดา (ตำรายากุมาร) พระคัมภีร์ธาตุวิภังค์ คัมภีร์สรรพคุณ มหาพิกัด พิกัดกระสาย สรรพคุณยาแก้ไข้ทรพิษ (เล่ม 1) · สมุฏฐานวินิจฉัย วรโยคสาร มหาโชตรัต ชวดาร โรคนิทาน ธาตุวิวรณ์ ธาตุบรรจบ มุจฉาปักขันทิกา ตักศิลา กษัย (เล่ม 2)
ข้อมูลมาจากไฟล์ `ZoodsP_ธาตุ4.xlsx` (ชีต AASYMA, ABHERA, ABRECI, ABADJT, ZOTEXT)

## มีอะไรบ้าง
1. **ทบทวน** – แผนผังกลุ่มอาการ A01–A21 (ธาตุเดียว สองธาตุ สามธาตุ สี่ธาตุ) แตะเพื่อดูโรค อาการ และคัมภีร์
2. **คัดแยกลงถาดธาตุ** – ลากหรือแตะการ์ดอาการลงถาด ดิน น้ำ ลม ไฟ (ระดับ 2: ชื่อโรค → คู่ธาตุ · ระดับ 3: ข้อความ → คัมภีร์) แล้วตรวจคำตอบพร้อมที่มา
3. **ทายคำถาม** – สุ่มชุดละ 10 ข้อ 8 แบบ: อาการ→โรค, โรค→กลุ่มธาตุ, ตัวยา→รสนำ, ตัวยา→ส่วนที่ใช้, โรค→คัมภีร์, กระสาย→รส, หัวข้อ→คัมภีร์, ข้อความ→คัมภีร์
4. **บัตรพลิก** – โรค→อาการ, ตัวยา→รส/สรรพคุณ, กระสาย→รส (บัตรที่ยังไม่แน่ใจจะกลับมาบ่อยขึ้น)
5. **รสยา** – รหัสรสและตัวยาเด่นของแต่ละรส
6. **คลังคัมภีร์ทั้งหมด** – หัวข้อตามสารบาญ สาระสำคัญพร้อมเลขหน้า และตำรับยาของแต่ละคัมภีร์
7. **รสยา 4 คัมภีร์** (`rasa.html`) – เทียบการใช้รสในฉันทศาสตร์ วรโยคสาร ธาตุวิภังค์ ธาตุวิวรณ์ พร้อมเลขหน้า: ตารางรส × โทษ บัตรรส 9 แผนที่ร่างกาย รสตามวัยและฤดู ขั้นใช้จริง จุดที่ตำราขัดกัน และเกมคัดแยก
8. **คะแนนของฉัน** – เก็บในเบราว์เซอร์เครื่องนั้น

## วิธีขึ้น GitHub Pages
1. สร้าง repository ใหม่บน GitHub (เช่น `thatu4-review`)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (`index.html`, `rasa.html`, โฟลเดอร์ `data`, `.nojekyll`, `README.md`) ไว้ที่ระดับบนสุดของ repository
3. ไปที่ **Settings → Pages** เลือก Source = *Deploy from a branch*, Branch = `main`, Folder = `/ (root)` แล้วกด Save
4. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repository>/`

เปิด `index.html` ในเครื่องโดยตรงได้เช่นกัน (ข้อมูลฝังอยู่ใน `data/zoods.js` ไม่ต้องมีเซิร์ฟเวอร์)

## หมายเหตุข้อมูล
- กลุ่มธาตุของภาวะยึดตามหัวข้อในคัมภีร์ บางรายการ (จากข้อ 26) เป็นการจัดกลุ่มของผู้สรุป ซึ่งระบุไว้ในอ้างอิง
- รสที่มีหมายเหตุ “รสเติม” มาจากตำราเภสัชกรรมไทยทั่วไป ไม่ได้มาจากสองเล่มนี้
- ตำรับจากปฐมจินดาและตำรายากุมารส่วนใหญ่ถอดด้วยโปรแกรมอ่านตัวอักษร ควรตรวจกับหน้าหนังสือก่อนใช้จริง
- เป็นสื่อเพื่อการเรียน ไม่ใช่คำแนะนำการรักษา
